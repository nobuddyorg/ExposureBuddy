# ExposureBuddy documentation

Organised by [Diátaxis](https://diataxis.fr): four kinds of document, one per
kind of need.

| You want to… | Read |
| --- | --- |
| Use the app for the first time | [Getting started](tutorials/getting-started.md) — tutorial |
| Do one specific thing in the app | [User guide](how-to/user-guide.md) — how-to |
| Run a check, replay a test failure, bump a pinned tool, regenerate icons or fixtures, deploy or roll back, move to a custom domain | [Developer guide](how-to/developer-guide.md) — how-to |
| Know what exists: the pipeline, the modules, the layer rules, the test ids, CI | [Architecture](reference/architecture.md) — reference |
| Know what a variable, threshold, port or limit is set to | [Configuration](reference/configuration.md) — reference |
| Know why something is built the way it is | [Design decisions](explanation/design-decisions.md) — explanation |

Local setup and the pre-PR checklist live in [CONTRIBUTING.md](../CONTRIBUTING.md);
the testing methodology in [TEST_STRATEGY.md](../TEST_STRATEGY.md). The guides
here link to both rather than repeat them.
